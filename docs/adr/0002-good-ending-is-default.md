# The Good Ending is the default, and the other endings are hidden without hand-holding

Players who follow the story's prompts reach the "Good Ending?" automatically. The Bad and Secret endings need deliberate, hidden discovery: freeing optional Bound creatures, collecting Old Faith knowledge, and choosing to speak the Verse. The game gives no quest log, no UI warning about saves, and no prompt for the final decisions. Each ending's epilogue holds one vague hint at the next. We chose this over making every ending reachable by an obvious choice because the intended experience is a second-playthrough "aha!", at the cost of some players never seeing the other endings.

## Consequences

- Marketing must state that multiple endings exist, because the game will not.
- Many save slots (20) replace any in-game save warning.
- The Unbinding choice is diegetic, appears only when all Verse pieces are held, and is never explained by the interface.
- Content for the Bad and Secret endings is only seen by a minority, so it should be cheap to build where it can be, such as reusing the crypt and the manor.
