---
name: building-features
description: Workflow for implementing any new game feature. Use whenever the owner asks to add, build, or change a feature.
---

Use subagents for every new feature:

- One Opus 5.5 subagent plans the feature and, afterwards, reviews the result.
- Sonnet 5.5 subagents implement it, at most 2 at a time.
- Subagents run at medium reasoning unless the owner says otherwise.

Report progress to the owner in plain, product-owner language, in small named pieces.
