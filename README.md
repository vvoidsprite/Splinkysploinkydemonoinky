# Lychkin

Godot 4.6 project wired to Claude Code via `@coding-solo/godot-mcp` (see `.mcp.json`).

Current state: a title screen, 20 save files, and a playable prologue (the gate, the entrance hall, and Maren's room with the save crow and the candle puzzle). Setup and test running are in `docs/godot.md`; how saving and story flags work is in `docs/save-system.md`.
